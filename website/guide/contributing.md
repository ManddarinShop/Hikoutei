# Contributing

Hikoutei's contribution guide lives in the repository:

- [CONTRIBUTING.md](https://github.com/ManddarinShop/Hikoutei/blob/develop/CONTRIBUTING.md)

It covers development setup (npm workspace incl. `packages/outbox`), branch
strategy (task branches → PR → `develop`), the Conventional Commits
convention, the pull request checklist, documentation rules, and the
benchmark recording rule.
